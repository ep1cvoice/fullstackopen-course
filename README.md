# Full Stack Open

This repository contains my work and exercises from the [Full Stack Open](https://fullstackopen.com/en/) course by the University of Helsinki.

I'm using this course to improve my skills in modern web development, including React, JavaScript, Node.js, TypeScript, databases, testing, and other full-stack technologies.

My goal is to complete the exercises independently, using documentation, Google, and AI tools for guidance when needed, while making sure I understand the code and the concepts behind it.

The repository is organized by course parts, with exercises and projects added as I progress through the course.
